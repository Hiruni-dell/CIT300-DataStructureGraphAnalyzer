# CIT300 Data Structure Graph Analyzer

Java project for demonstrating core data structures and graph traversal algorithms.

## Features
- Arrays and array operations
- Custom linked list
- Stack and queue
- Searching algorithms
- Graph traversal using BFS and DFS
- Basic performance analysis

## Requirements
- JDK 17 or newer
- Eclipse IDE (optional)

## Run
From the project directory, compile the Java source files:

```bash
javac -d out src/analyzer/*.java
java -cp out analyzer.Main
```

## Testing
```bash
javac -d out src/analyzer/*.java
java -cp out analyzer.AnalyzerSelfTest
```
